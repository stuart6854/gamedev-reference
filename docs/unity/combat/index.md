# Combat

Firing and melee chains. Health stays under [Systems](../systems/index.md): a hazard and a gun spend the same pool.

Written:

- [Hit flash](hit-flash.md) — an emissive fade or a material swap on every landed hit, and a sprite version.
- [Damage numbers](damage-numbers.md) — pooled world-space popups that merge rapid hits and colour by damage type.
- [Weapons](weapons.md) — a shared definition, fire modes, hitscan, pooled projectiles, ammo, recoil, and a holder that switches weapons.
- [Bullet tracers](tracers.md) — a shot event for every hitscan shot, every Nth round, pooled line streaks, one shared particle system, and projectile trails that fade where the shot ends.
- [Attack combos](combos.md) — light and heavy chains as a step tree, hit and combo windows, an input buffer, and one hit per target per swing.

Lock-on targeting is still on the [roadmap](../../roadmap.md#combat).
