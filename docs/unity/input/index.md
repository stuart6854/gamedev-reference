# Input

Input with the **Input System** package, which Unity 6 projects use by default.

Written:

- [Rebinding](rebinding.md) — players change their own bindings: interactive rebinding, cancel and excluded controls, duplicates, composite parts such as WASD, keyboard and gamepad groups, and saving the overrides.

Most pages on this site read devices directly, such as `Keyboard.current` and `Mouse.current`, to keep samples short. Rebinding only affects input read through actions. The rebinding page shows the switch.

An overview of the Input System and the legacy Input Manager, including projects with both enabled, is still planned.
