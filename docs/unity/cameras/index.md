# Cameras

Views that follow a player. Each page is a plain script first, with a Cinemachine 3 variant where Cinemachine makes the setup shorter.

Written:

- [Third-person orbit camera](../orbit-camera.md) — orbit, zoom, and collision pull-in, as a plain script and as Cinemachine 3.
- [First-person camera](first-person.md) — mouse and stick look, cursor lock, a pitch clamp, and a distance-driven head bob, for a CharacterController or a Rigidbody body.
- [Top-down strategy camera](rts.md) — key, edge, and drag pan, zoom towards the cursor with pitch tied to zoom, rotation around the focus, map bounds, and terrain height.

Camera framing is still on the [roadmap](../../roadmap.md#cameras).
