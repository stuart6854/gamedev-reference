# Tools

Working on the game rather than in it: editor extensions that save designers time and catch mistakes, and finding out where the frame time goes.

Written:

- [Editor tooling](editor/index.md) — custom inspectors and property drawers, menu items, editor windows and scene handles, and validation that runs on demand and on build.
- [Profiler walkthrough](profiler.md) — profiling a development build, reading the CPU view, finding allocations, custom markers, and an in-game stats readout.

Debug drawing, an in-game console, and the Unity Test Framework are on the [roadmap](../../roadmap.md#tools).
